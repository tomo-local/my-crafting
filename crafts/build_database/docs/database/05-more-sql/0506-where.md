# 0506: WHERE句の式化

- 元ページ: https://trialofcode.org/database/0506_where_expr/

## このステップで学ぶこと

- 従来はキー配列などの固定形式で扱っていたWHERE句を、汎用的な式（expression）オブジェクトとして扱うようにリファクタリングする
- 新機能追加というより、既存のWHERE処理を式ツリーベースの表現に置き換える設計変更が主眼

## 要点

- SELECT・UPDATE・DELETEの各ステートメント構造体に、条件を保持する `cond` フィールド（`interface{}` 型）を追加し、式ツリーとして条件を持たせる
- 実装は3つのコンポーネントに分かれる
  - `parseWhere()`: WHERE句の条件部分を式としてパースする
  - `matchPKey()`: 式から主キーの値を抽出する
  - `matchAllEq()`: `a = 123 AND b = 456` のような「等価条件のAND結合」を再帰的に走査して認識する
- 現段階では「主キーを完全に指定して単一行を返すクエリ」のみに対応する限定的な実装

## 実装のポイント / 注意点

- 従来のキー配列形式から式ツリー形式への移行なので、既存の呼び出し箇所（SELECT/UPDATE/DELETEの実行部分）を式ベースの `cond` を使うよう書き換える必要がある
- 範囲検索（`a > 123` など）にはまだ対応しておらず、次ステップ（0507）で実装される
- `matchAllEq()` のような「式ツリーを再帰的にたどってパターンを認識する」処理は、以降のステップでも繰り返し出てくる考え方なので、ここでしっかり理解しておくと良い
