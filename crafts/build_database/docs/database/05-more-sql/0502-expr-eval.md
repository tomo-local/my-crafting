# 0502: 式の評価（evalExpr）

- 元ページ: https://trialofcode.org/database/0502_expr_eval/

## このステップで学ぶこと

- 0501で構築したAST（式木）を実際に「計算」して値を得る評価器（evaluator）を実装する
- SELECT・UPDATE文で数式演算（`a + b`, `a * 4 - b` など）を扱えるようにするための基礎部分

## 要点

- 評価の原則は「部分木を先に計算してから、現在のノードを計算する」という再帰的なボトムアップ処理
- `evalExpr()` は被演算子の型を判定して処理を分岐する（型スイッチ）
  - 文字列型 → 列名参照。行データから対応するカラムの値を取り出す
  - `*Cell` 型 → リテラル値。そのまま返す
  - `*ExprBinOp` 型 → 左右を再帰的に `evalExpr()` した上で、演算子に応じた計算を行う
- 関数シグネチャは `(*Cell, error)` を返す形にし、失敗時にはエラーを即座に伝播させる

## 実装のポイント / 注意点

- 左右の子ノードを評価する際、それぞれで発生したエラーをすぐにチェックして早期リターンする（エラーの握りつぶし・無視をしない）
- 列参照の解決（カラム名→値のルックアップ）と、実際の演算ロジック（加減乗除・比較など）はこの段階ではTODOとして残されており、自分で実装する必要がある
- 型アサーション（type switch）を使う設計は、0501のインターフェース設計と対になっている。ASTのノード形状を変えると評価器側の分岐も連動して変更が必要になる点に注意
