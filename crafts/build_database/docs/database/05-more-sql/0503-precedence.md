# 0503: 演算子の優先順位

- 元ページ: https://trialofcode.org/database/0503_op_precedence/

## このステップで学ぶこと

- `a + b * c` のような式で `*` が `+` より先に評価されるべき、という優先順位をパーサでどう実現するかを学ぶ
- 再帰下降パーサにおける「優先順位の階層」というパターンを理解する

## 要点

- 複数の優先度レベルを持つ中置式を解析するときは、**最も低い優先度の関数から開始する**のが基本原則
- 優先度の階層は関数の呼び出し階層として表現される
  - `parseExpr() → parseAdd() → parseMul() → parseAtom()`
  - 各レベルが「次に低い優先度」の関数を呼び出し、その戻り値同士を自分のレベルの演算子でつなぐ
- `parseMul()` は `parseAdd()` をコピーして演算子を `* /` に絞ったもの
- `parseAdd()` は内部で呼んでいた `parseAtom()` を `parseMul()` に置き換えることで、乗除が加減より先に結合されるようにする
- 括弧 `(...)` は `parseAtom()` の中で検出し、そこから最上位の `parseExpr()` を再帰呼び出しすることで優先順位を一旦リセットする

## 実装のポイント / 注意点

- このパターン（各優先度ごとに1関数、下位を呼んで演算子でつなぐ）は非常に規則的なので、優先度レベルを増やしたい場合は同じ形の関数を追加するだけでよい
- 括弧内で `parseExpr()` を再帰呼び出しする部分が、優先順位を「リセット」する仕組みのキモ。ここを理解していないと括弧のネストが正しく処理できない
- 次ステップ（0504）で比較演算子・論理演算子・単項演算子まで含めた完全な優先順位階層に拡張する
