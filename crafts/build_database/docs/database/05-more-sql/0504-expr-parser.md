# 0504: 全演算子に対応した式パーサ

- 元ページ: https://trialofcode.org/database/0504_all_expr/

## このステップで学ぶこと

- 0503で作った優先順位の階層パターンを拡張し、SQLで必要な演算子を一通りサポートする完全な式パーサを完成させる
- 単項演算子（NOT, 単項マイナス）という新しい種類の演算にも対応する

## 要点

- 優先順位は低い順に以下の階層になる
  - `OR` → `AND` → `NOT`（単項） → 比較演算子（`=`, `<>`, `<`, `>`, `<=`, `>=`） → 加減（`+`, `-`） → 乗除（`*`, `/`） → 単項マイナス（`-a`）
- 各優先度レベルの処理ロジックが似ているため、共通部分を `parseBinop()` に抽出し、対象となる演算子トークン群と次に呼ぶ関数をパラメータとして渡す設計にする
- 単項演算子は二項演算とは構造が異なるため、`ExprUnOp` という新しい構造体を導入する
  - `parseNot()` と `parseNeg()` がそれぞれ `NOT` と単項マイナスを専門に処理する

## 実装のポイント / 注意点

- 二項演算用のコードをコピペし続けると保守が大変になるため、共通ロジックの関数化（`parseBinop()`）が重要な設計判断になる
- `ExprUnOp` を追加したら、評価器 `evalExpr()`（0502）側にも対応する型スイッチの分岐を追加しないと動かない点に注意
- 優先順位の階層が深くなるほど呼び出しコストは増えるが、再帰下降パーサとしては素直で理解しやすい実装になる
- ここまでで式パーサ自体は完成し、次ステップ以降はこれをSELECT/UPDATE/WHEREの実処理に統合していく
