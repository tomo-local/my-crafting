# 0405: 範囲クエリ

- 元ページ: https://trialofcode.org/database/0405_range_query/

## このステップで学ぶこと

- KV層およびデータベース層に、両端（開始・終了）を指定できる範囲クエリ機能を実装する
- SQLの比較条件（`>`, `>=`, `<`, `<=`）とORDER BYの昇順・降順を、統一的なイテレータ機構で表現する

## 要点

- これまでの`Seek()`は片側だけの検索（`key >= 123`）にしか対応していなかったが、新たに`Range()`メソッドを導入し、開始条件と終了条件の両方を指定できるようにする
- `desc`フラグで昇順・降順を切り替える。開始条件の演算子（`>=`/`>`なら昇順、それ以外なら降順）から走査方向を決定するマッピングを行う
- 複合キーの部分一致（プレフィックス）検索に対応するため、「無限大」の概念を導入してプレフィックスを完全なキーに正規化する
  - 空文字列を`-∞`（最小値）として扱う
  - `0xff`バイトを`+∞`（最大値）として扱う
  - 各カラムの前に型情報バイトを挿入し、実データが`0xff`で始まった場合の衝突を回避する
  - トレーリングの`0x00`を追加し、`-∞`との衝突を防ぐ
- `RangedKVIter`は既存の`KVIterator`をラップし、`Valid()`で停止条件をチェックし、`Next()`で昇順・降順に応じた移動制御を行う設計

## 実装のポイント / 注意点

- StartとStopのプレフィックス長は一致している必要はないが、比較演算子（`>`/`>=`/`<`/`<=`）の扱いを誤ると意図しない範囲になるため注意
- 無限大の符号化方式を採用する結果、生データのキーが`0xff`から始まることは許容されない制約が生じる
- DB層の`Range()`実装は読者に委ねられている部分がある
- 次の0501（二項演算式）では、この範囲クエリ機能を土台に、より複雑なWHERE句の処理へと進む
