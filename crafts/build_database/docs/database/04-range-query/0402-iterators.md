# 0402: KVイテレータ

- 元ページ: https://trialofcode.org/database/0402_kv_iterator/

## このステップで学ぶこと

- 異なるデータ構造を統一的に走査できる、共通のイテレータインターフェースを設計・実装する
- 配列ベースのKVストアに対する具体的なイテレータ実装を通じて、走査の基本操作（Seek/Next/Prev）を理解する

## 要点

- データ構造ごとに必要なメソッドは異なるため、それらを抽象化する共通インターフェースが必要になる。インターフェースは`Seek()`（開始位置指定）、`Valid()`（走査終了判定）、`Key()`/`Val()`（現在要素へのアクセス）、`Next()`/`Prev()`（移動）から構成される
- 将来ディスクベースの実装に移行した際にI/Oエラーが発生しうるため、各メソッドは`error`を返せる設計にしておく
- 位置が`-1`または配列長と等しい状態を「範囲外」と定義する。この設計により、範囲外の位置から1歩戻れば範囲内に戻るという対称的な振る舞いが実現できる
- `Seek()`は「キー >= ターゲット」を満たす最初の位置を返す仕様とし、バイナリサーチの結果（0401で作った挿入位置ロジック）とそのまま統合できる

## 実装のポイント / 注意点

- `KVIterator`は`keys`/`vals`への参照と現在位置`pos`を保持するだけのシンプルな構造体でよい。`Next()`/`Prev()`は`pos`の単純な増減で実装できる
- 現在の配列ベース実装は過渡的なものであり、データ構造が変わればイテレータの実装も大きく変わる想定
- 次の0403では、キーの比較がバイト列の辞書式順序に一致するようなエンコーディング（順序保持エンコーディング）を扱う
