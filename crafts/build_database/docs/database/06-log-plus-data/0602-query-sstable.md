# 0602: SSTableへの問い合わせ（Query SSTable）

- 元ページ: https://trialofcode.org/database/0602_sst_search/

## このステップで学ぶこと

- 前ステップで作成したSSTableをディスクから効率的に読み込む方法を学ぶ
- ファイル全体をメモリに載せずにランダムアクセスで検索できるイテレータを実装する

## 要点

- ディスク上のフォーマットは `[]struct{ key []byte; val []byte }` を直列化したものをそのまま活用する
- `ReadAt()` は `WriteAt()` に対応する読み取り操作で、ファイルの任意オフセットから直接読み出せる
- `SortedFile` 構造体に `nkeys`（キー数）フィールドを追加し、ファイル内のKVペア数を管理する
- `Seek()` は具体的な型ではなくインターフェース `SortedKVIter` を返すことで、呼び出し側を実装の詳細から疎結合にする

## 実装のポイント / 注意点

- `index()` メソッドはオフセット配列の位置（`8 + 8*pos` など）からオフセット値を読み、そこから実データを取得する2段構えの処理になる
- ファイル破損を検出するロジックを組み込んでおく必要がある
- イテレータは `Valid()` / `Key()` / `Val()` / `Next()` / `Prev()` で構成され、ディスクI/Oが発生するため `Next()` / `Prev()` はエラーを返す設計にする
- 全データをメモリに読み込まないことで、データサイズに対するスケーラビリティを確保している
