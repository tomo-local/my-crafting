# 0601: SSTableの構築（Build SSTables）

- 元ページ: https://trialofcode.org/database/0601_sst_encode/

## このステップで学ぶこと

- メモリ内のソート済みデータをディスク上のファイルフォーマットとして書き出す方法を学ぶ
- LSM-Treeの中核コンポーネントであるSSTable（Sorted String Table）の構造を実装する

## 要点

- SSTableはMemTable（メモリ内のソート済み構造）をフラッシュして作られるディスク上のファイル
- 既存のログと定期的にマージされ、新しいSSTableファイルに置き換わっていく運用を前提とする
- ファイルフォーマットは大きく3部構成
  - キー数
  - オフセット配列（各KVペアの位置を記録し二分探索を可能にする）
  - KVペア本体（`キー長|値長|キーデータ|値データ`の並び）
- 書き込み対象は具体的な型ではなく `SortedKV` インターフェース経由で受け取ることで、データ源に依存しない汎用的な設計にしている

## 実装のポイント / 注意点

- オフセット配列を持たせることで、後続ステップの二分探索によるランダムアクセスが可能になる
- `WriteAt()` を使い、オフセット配列とKV本体を1回のパスで書き込むことで効率的な実装にしている
- ここではまだ「書き込み」のみで、「読み込み（検索）」は次のステップ0602で扱う
