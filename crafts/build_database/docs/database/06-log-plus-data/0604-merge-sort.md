# 0604: マージソートによる統合（Merge Sorted Data）

- 元ページ: https://trialofcode.org/database/0604_merge_sort/

## このステップで学ぶこと

- MemTable（メモリ内）とSSTable（ディスク上）という複数のデータ源を横断して問い合わせる方法を学ぶ
- 複数のソート済みイテレータをマージソートの要領で統合する仕組みを実装する

## 要点

- データがMemTableとSSTable（さらに複数レベルのSSTable）に分散すると、同じキーが複数箇所に重複して存在しうる
- 優先度ルール: 「上位レベルは下位レベルより優先される」（新しいデータほど優先）
- 単一キー検索であればレベルを順番に確認するだけで済むが、範囲クエリでは「全レベルから最小（または最大）キーを選び続ける」典型的なマージソートが必要になる
- LevelDB というデータベース名は、この「レベルをマージする」発想に由来する
- 実装は `MergedSortedKVIter` 構造体で表現し、`which` 変数で現在最小（または最大）キーを持つイテレータを追跡する

## 実装のポイント / 注意点

- 重複キーが複数レベルに存在する場合、出力に重複を含めないよう制御する必要がある
- 昇順・降順を途中で切り替えるような操作にも対応できる設計にする
- ここではまだ「削除」の扱いは明示的に出てこないが、次ステップ0605で削除マーカーの必要性が顕在化する
