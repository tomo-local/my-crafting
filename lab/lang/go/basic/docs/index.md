# Go 基礎 学習ロードマップ

## 目的

Go の基本構文を手を動かして身につける。  
「変数を宣言して関数に渡し、結果を制御フローで処理してコレクションに格納する」という基本的な流れを自分の言葉で書けるようになることがゴール。

## 学習順序

| # | ドキュメント | トピック |
|---|---|---|
| 1 | [変数・型・定数](./01_types.md) | var / := / const、ゼロ値、型推論 |
| 2 | [関数](./02_functions.md) | 複数戻り値、エラー慣用句 |
| 3 | [制御フロー](./03_control_flow.md) | if / for / switch / defer |
| 4 | [スライス・マップ](./04_collections.md) | append / range / 存在確認 |

## 進め方

1. ドキュメントを読んでコンセプトを把握する
2. `main.go` の該当セクションのコメントアウトを外して実行する
3. 写経したあと自分でコードを書き換えて挙動を確かめる

```bash
mise exec -- go run main.go
```
